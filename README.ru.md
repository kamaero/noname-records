# Noname Records

[English](README.md) · **Русский**

Noname Records — устанавливаемая на свой компьютер или сервер система для студии многоголосой озвучки книг. Загрузите книгу, проверьте разметку ролей, соберите каст, примите записи, сверьте их с текстом и скачайте проект главы для Adobe Audition.

Система использует ваши ключи нейросетевых сервисов. Сами сервисы могут брать плату: перед запуском проверьте их условия, тарифы и смету. Текст и записи отправляются только выбранным вами сервисам. Программа бесплатна и распространяется по [лицензии AGPL-3.0](LICENSE).

## Возможности

- Загрузка книг в форматах `.txt`, `.docx`, `.fb2` и `.epub` на английском или русском языке. Язык книги выбирается при загрузке; интерфейс системы — на английском.
- Поиск персонажей, проверка разметки реплик в Читалке и работа с кастом.
- Публикация глав актёрам, приём дублей и сверка записей с текстом с помощью распознавания речи.
- Выгрузка проектов глав для Adobe Audition. Дополнительно доступны работа со звуком и эмбиентом и уведомления через Telegram.

Результаты нейросетей необходимо проверять вручную. Доступность провайдеров, качество моделей и стоимость зависят от ваших настроек.

## Что понадобится

- Mac или Windows с Docker Desktop и не менее 8 ГБ оперативной памяти либо сервер Linux с Docker Compose.
- Интернет для установки и работы с внешними нейросетевыми сервисами.
- Ключи выбранных провайдеров: их можно ввести при установке или позднее в **Settings → AI providers**.
- Домен и HTTPS для удалённой работы участников или подключения Telegram-бота.

Учёт расходов и лимитов сейчас ведётся в рублях. Неизвестная цена не означает, что запрос бесплатен: такие расходы могут не входить в лимит. Перед платным запуском проверяйте смету и настройки провайдера.

## Установка на Mac

1. Установите и запустите [Docker Desktop](https://www.docker.com/products/docker-desktop/).
2. Откройте Терминал и выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/kamaero/noname-records/main/get.sh | bash
```

3. Следуйте подсказкам, задайте логин и пароль администратора и выберите локальный режим. Ключи можно добавить позднее.
4. Откройте [http://localhost:8080](http://localhost:8080) и войдите.

## Установка на Windows

Установите и запустите Docker Desktop с включённым WSL 2, затем выполните в PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/kamaero/noname-records/main/get.ps1 | iex"
```

Следуйте подсказкам и откройте [http://localhost:8080](http://localhost:8080).

## Установка на сервер

Направьте DNS A-запись домена на сервер Linux, подключитесь к нему и замените `studio.example.com` своим доменом:

```bash
curl -fsSL https://raw.githubusercontent.com/kamaero/noname-records/main/get.sh | bash -s -- --domain studio.example.com
```

Установщик настроит Docker и HTTPS. Откройте свой домен и войдите. Для необязательного Telegram-бота понадобятся собственные токен бота и секрет вебхука; храните их в тайне.

## Первые шаги

1. Войдите и настройте ключи и модели в **Settings → AI providers**.
2. Добавьте книгу-пример или загрузите свою книгу, выбрав её язык. Проверьте смету перед запуском анализа.
3. Проверьте разметку в Читалке, исправьте спорные места и соберите каст.
4. Создайте учётные записи актёров, опубликуйте главы и примите записи.
5. Проверьте результаты распознавания и скачайте проект главы для сведения.

## Обслуживание

Выполняйте команды из папки установки (`~/noname-records` на Mac/Linux или `$HOME\noname-records` в Windows PowerShell):

| Действие | Mac / Linux | Windows PowerShell |
|---|---|---|
| Обновление | `./update.sh` | `powershell -ExecutionPolicy Bypass -File update.ps1` |
| Резервная копия | `./backup.sh` | `powershell -ExecutionPolicy Bypass -File backup.ps1` |
| Остановить / запустить | `docker compose stop` / `docker compose up -d` | те же команды |
| Посмотреть журнал | `docker compose logs --tail 100 web worker` | та же команда |

Обновление сначала создаёт резервную копию. Храните дополнительную копию отдельно от сервера. Папка `data` содержит базу и записи; файл `.env` — настройки и секреты.

Если Docker недоступен, запустите Docker Desktop и дождитесь его готовности. Если сервер не открывается, проверьте DNS и HTTPS; после исправления DNS перезапустите Caddy командой `docker compose restart caddy`. Хеш пароля администратора можно создать командой `docker compose run --rm web python scripts/generate_password_hash.py`. Состояние вебхука Telegram проверяется командой `docker compose exec web python -m scripts.telegram_set_webhook --info`.

## Разработка

Python 3.12, FastAPI, SQLAlchemy, Alembic, SQLite, RQ и Redis; React 18, TypeScript и Vite.

```bash
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt -r requirements-dev.txt
.venv/bin/python -m pytest -q
cd frontend && npm ci && npm run build
```

Перед публикацией выполните `scripts/release_audit.py --tree --history --release`, указав необходимые базы людей и книг в режиме только для чтения. Не публикуйте частные книги, записи, имена и секреты.
